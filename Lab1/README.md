# Лабораторная работа №1 — Процедурное программирование (C#)

Решены **чётные задачи (2, 4, 6, 8, 10)** из каждого из 4 заданий — всего 20 задач.

Всё решение оформлено как **один класс `Lab1` в одном файле `Lab1.cs`**.

## Что внутри `Lab1.cs`

| Часть | Содержимое |
|-------|-----------|
| Ввод и `Main` | Методы ввода с проверкой, метод `Main`, главное меню |
| Задание 1 «Методы» | `sumLastNums`, `isPositive`, `isUpperCase`, `isDivisor`, `lastNumSum` |
| Задание 2 «Условия» | `safeDiv`, `makeDecision`, `sum3`, `age`, `printDays` |
| Задание 3 «Циклы» | `reverseListNums`, `pow`, `equalNum`, `leftTriangle`, `guessGame` |
| Задание 4 «Массивы» | `findLast`, `add`, `reverse`, `concat`, `deleteNegative` |

## Файлы проекта

Кроме `Lab1.cs` в папке есть `Lab1.csproj` и `Lab1.sln` — это файлы проекта, благодаря им папка открывается в JetBrains Rider без дополнительных настроек.

## Как запустить (JetBrains Rider)

1. Откройте Rider и нажмите **Open**.
2. Выберите файл `Lab1.sln` из этой папки.
3. Подождите, пока Rider загрузит проект.
4. Нажмите зелёный треугольник (Run) справа вверху.

Если Rider пишет, что не найден .NET SDK, откройте `Lab1.csproj` и замените `net8.0` на установленную версию.

## Как пользоваться

В главном меню выберите задание (1–4), затем номер задачи (2, 4, 6, 8 или 10) и вводите данные по подсказкам. `0` — вернуться назад или выйти.

Массивы вводятся одной строкой через пробел, например: `1 2 3 4 5`.
