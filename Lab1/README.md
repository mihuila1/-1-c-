# Лабораторная работа №1 — Процедурное программирование (C#)

Чётный вариант: из каждого задания выполнены задачи **2, 4, 6, 8, 10**
(всего 20 задач).

## Структура проекта

| Файл            | Назначение                                                            |
|-----------------|-----------------------------------------------------------------------|
| `Program.cs`    | Метод `Main`: меню, ввод данных с проверкой, вызов всех методов      |
| `Lab1Tasks.cs`  | Класс `Lab1Tasks` с методами-решениями всех задач                     |
| `Lab1.csproj`   | Файл проекта (.NET 8)                                                 |

## Запуск

Требуется [.NET SDK 8.0](https://dotnet.microsoft.com/download) или новее.

```bash
dotnet run
```

Либо создайте консольный проект в Visual Studio и добавьте в него файлы
`Program.cs` и `Lab1Tasks.cs`.

## Как пользоваться

В главном меню выберите задание (1–4), затем номер задачи. Данные вводятся
с клавиатуры; при неверном вводе программа выводит сообщение об ошибке и
повторяет запрос. Массивы вводятся через пробел, например: `1 2 3 4 2 2 5`.

## Примечания к реализации

- `sumLastNums` работает и с отрицательными числами (суммируются модули цифр).
- `safeDiv` при `y == 0` возвращает `0`, не допуская исключения.
- `makeDecision` возвращает строки вида `5 < 7`, `8 > -1`, `4 == 4`.
- `age` корректно обрабатывает исключения 11–14 (`11 лет`, `112 лет`).
- `printDays` использует `switch` (без `if`), регистр и пробелы по краям игнорируются.
- `pow` принимает только `y >= 0`; при переполнении `int` выбрасывается `OverflowException`,
  который обрабатывается в `Main`.
- `guessGame` не засчитывает некорректный ввод как попытку.
- `add` вставляет значение в позицию `pos` (`0 <= pos <= arr.Length`), исходный массив не меняется.
- `reverse` меняет исходный массив «на месте»; остальные методы массивов возвращают новый массив.
- Нуль в `deleteNegative` сохраняется (удаляются только значения `< 0`).

## Примеры

```
sumLastNums(4568)                         -> 14
isDivisor(3, 6)                           -> True
safeDiv(5, 0)                             -> 0
age(31)                                   -> "31 год"
reverseListNums(5)                        -> "5 4 3 2 1 0"
pow(2, 5)                                 -> 32
findLast([1,2,3,4,2,2,5], 2)              -> 5
add([1,2,3,4,5], 9, 3)                    -> [1, 2, 3, 9, 4, 5]
deleteNegative([1,2,-3,4,-2,2,-5])        -> [1, 2, 4, 2]
```
